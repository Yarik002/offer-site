Профиль соответствует уровню сильного Junior Python Backend: есть 1,5+ года практической разработки, FastAPI, PostgreSQL, Docker, очереди задач, интеграции внешних API и покрытые тестами проекты. Наиболее убедительно кандидат выглядит на позициях Python Backend и AI Automation, а проекты с биллингом, LLM API, OCR и транскрибацией хорошо отвечают вакансиям из списка. Основной риск — отсутствие в резюме подтверждённого production-опыта, CI/CD, observability и формального описания результатов; при доработке материалов шансы на junior-отклики высокие.

✅ Сильные стороны

  • 1 год 9 месяцев практической Python-разработки с реальными проектами в финтехе, ботах и автоматизации
  • Уверенное владение FastAPI, PostgreSQL, SQLAlchemy 2.0, Alembic и проектированием REST API
  • Есть опыт фоновых задач, Celery Beat, Redis, интеграции API, retry и exponential backoff
  • Реализованы Telegram-боты с платежами, подписками, распознаванием чеков и LLM-функциями
  • Практический DevOps-контекст: Docker Compose, Linux, Nginx, PostgreSQL, Redis и развёртывание на VPS
  • Хорошая тестовая культура: 100+ unit-тестов, интеграционные тесты, fixtures, mocks и линтеры
  • Есть публичные репозитории с проектами, непосредственно релевантными backend- и AI-разработке

⚠️ Слабые места

  • Не указано, работали ли проекты с реальной пользовательской нагрузкой и каким был production-мониторинг
  • В резюме не описаны CI/CD-процессы: проверка тестов, линтеров и сборка образов в GitHub Actions или GitLab CI
  • AI-опыт описан через конкретные API, но отсутствуют подробности о prompt engineering, оценке качества и ограничении токенов
  • Не выделено достижения с бизнес-эффектом: сколько пользователей, запросов, транзакций или сэкономленного времени
  • Нет ясного распределения времени между коммерческой разработкой, фрилансом и учебными проектами
  • Технологический уровень Python, SQL и Linux не подтверждён независимой оценкой или профессиональным английским
